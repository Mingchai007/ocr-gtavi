# สไตล์ซับไทย (ใช้ทั้งตอนเกลาคลังและตอนแปลสด — แก้ไฟล์นี้ได้ตามใจชอบ)

เป้าหมาย: อ่านแล้วรู้สึกเหมือนดูหนังซับไทยดีๆ ไม่ใช่คำแปลจากเครื่อง

## 1. สั้น อ่านทัน
- 1 บรรทัดซับควรอ่านจบใน 1-2 วินาที (ประมาณไม่เกิน 40 ตัวอักษร) ถ้ายาวให้ตัดคำฟุ่มเฟือย แต่ห้ามตัดความหมายหลัก
- ตัดคำเติมที่ไม่มีความหมาย: you know, like, I mean, uh, um, so, man, dude, bro (ใส่ "เพื่อน" "แบบ" "คือ" ได้บ้างถ้าช่วยให้มีรสชาติ)
- ภาษาไทยละประธานได้ ถ้าบริบทชัดอยู่แล้วไม่ต้องใส่ "ฉัน/กู/คุณ" ทุกประโยค

## 2. พูดแบบคนไทยพูดจริง ไม่ใช่แปลตรงตัว
- ห้ามใช้โครงสร้างแปลตรงตัว: "มันถูก...", "ซึ่ง...", "สิ่งที่...คือ", "คุณรู้ไหม", "ของฉัน" ซ้ำซาก, "ทำให้ฉันรู้สึก"
  - "It's encrypted" -> "มันเข้ารหัสไว้" (ไม่ใช่ "มันถูกเข้ารหัสไว้")
  - "You know what I'm saying?" -> "เก็ตป่ะ" / "เข้าใจนะ"
  - "I got you" -> "จัดให้" / "ได้เลย" / "ไว้ใจได้"
- สำนวนอังกฤษให้แปลความหมาย ไม่แปลคำต่อคำ
- ใช้คำลงท้ายแสดงอารมณ์ให้เป็นธรรมชาติ: วะ ว่ะ เว้ย ดิ สิ นะ น่า เหอะ หรอก ล่ะ เนี่ย ป่ะ
- คำทับศัพท์ที่คนไทยใช้จริงใช้ได้เลย: โอเค แอป ไลฟ์ เช็ก ดีล บอส

## 3. สรรพนามตามความสัมพันธ์ (สำคัญที่สุด)
- **ละสรรพนามให้มากที่สุด** แบบซับหนังไทย ใส่เฉพาะตอนที่ไม่ใส่แล้วงงว่าใครทำอะไร
  - "I'm going to the gun shop tomorrow" -> "พรุ่งนี้จะไปร้านปืน" (ไม่ใช่ "พรุ่งนี้ฉันจะไปร้านปืน")
  - "Did you see that?" -> "เห็นมั้ย?" (ไม่ใช่ "นายเห็นนั่นมั้ย?")
- ซับต้นฉบับไม่บอกว่าใครพูด ให้อ่านทั้งฉากแล้วเดาคนพูด/คนฟัง และใช้สรรพนามเดียวกันตลอดฉาก
- กู/มึง: เพื่อนสนิทคุยกันเอง, พวกแก๊ง/อาชญากรคุยกัน, ทะเลาะ ด่า ข่มขู่
- ฉัน/นาย, ฉัน/เธอ, เรา: คู่รัก คนรู้จักทั่วไป ผู้หญิงพูดทั่วไป
- ผม/คุณ, ฉัน/คุณ (+ครับ/ค่ะ เมื่อสุภาพ): คนแปลกหน้า พนักงาน ลูกค้า เจ้าหน้าที่ ตำรวจคุยกับประชาชน ข้อความฝากเสียง
- วิทยุตำรวจ/ประกาศ: ภาษาทางการสั้นๆ ไม่ใช้กู/มึง
- ไม่แน่ใจ -> ละสรรพนาม หรือใช้ ฉัน/นาย (กลางๆ) ดีกว่าใส่ กู/มึง มั่ว

## 4. คำหยาบ (เรต 18+)
- ต้นฉบับหยาบ -> ไทยต้องหยาบแรงเท่ากัน ห้ามเซ็นเซอร์ ห้ามใช้ "ให้ตายสิ" "เจ้าบ้า"
  - fucking (คำเสริม) -> แม่ง/โคตร/เหี้ย, what the fuck -> เหี้ยไรวะ/อะไรวะเนี่ย
  - motherfucker -> ไอ้เหี้ย/ไอ้สัส, bitch (ด่า) -> อีดอก/อีเหี้ย, shit -> ชิบหาย/เหี้ย, fuck you -> ไปตายซะ/ไอ้สัส
  - [__] = คำหยาบที่ YouTube เซ็นเซอร์ ให้เดาจากบริบท
- ต้นฉบับไม่หยาบ -> ห้ามเติมคำหยาบ (กู/มึง ระหว่างเพื่อนไม่นับเป็นคำหยาบ)
- เพื่อนแซวกันใช้หยาบแบบขำๆ ทะเลาะ/ยิงกันใช้คำแรง

## 5. รูปแบบซับ
- ไม่ใส่จุด (.) ท้ายประโยค ไม่ใช้จุลภาค ใช้เว้นวรรคแบ่งวลีแทน
- ประโยคคำถามให้ลงท้ายด้วย ? เสมอ ใช้ ! ได้ (ไม่ซ้อนหลายตัว) ใช้ ... เมื่อพูดค้างหรือถูกขัด
- ตัวเลขเงินใช้แบบคนพูด: "พันนึง" "ห้าหมื่น" "2 ล้าน"
- ชื่อคน/สถานที่ใช้ตาม glossary ชื่อที่ไม่มีใน glossary ให้ทับศัพท์ตามเสียงอ่าน
